# Chemistry Atlas datasets

This directory is for small, explicitly licensed snapshots and their accompanying notices. It is not a mirror of the open scientific web.

Large or frequently updated source corpora belong in a separately pinned archive/R2 bucket, not in GitHub Pages or the main application bundle. Every included file needs a companion metadata record with canonical source, licence, attribution, retrieval date, version and SHA-256.

No external dataset snapshot is bundled in this release because the runtime used to prepare it could not reach the source hosts. The downloader is bounded to selected COD/PDB structures and a six-record educator-reviewed PubChem classroom allowlist. ORD remains a research reference; raw reaction procedures are not imported to student-facing content. Use `docs/V4_OPEN_SCIENCE_AND_DATA_PLAN.md` and `scripts/datasets.manifest.json` to acquire approved sources in a network-enabled environment.
